# Adding an app to velkmoor.com

The site is static HTML + one stylesheet (`assets/site.css`). No build step. Privacy and support
pages keep their own style (`assets/app.css`). Never rename or delete an existing URL.

Example below uses the slug `newapp`. The slug is the URL folder: `velkmoor.com/newapp/`.

## 1. Images (5 minutes)

```
python3 _tools/export_app_images.py newapp <path>/AppIcon-1024.png \
  en:today:<path>/store_screenshots/iphone_6.9/en/01_xxx.png \
  en:feature1:<path>/store_screenshots/iphone_6.9/en/02_xxx.png \
  ja:today:<path>/store_screenshots/iphone_6.9/ja/01_xxx.png  ...
```

- Input: the 1024 app icon and the 1320×2868 App Store screenshots (the caption is cut off; only the phone screen is kept).
- Output: `assets/img/newapp/icon-512.(png|webp)`, `icon-180.png`, `icon-128.(png|webp)`, `<name>-<lang>.(webp|jpg)`.
- You need 1 hero screen + 3–4 feature screens, plus 1 screen for the home-page card.
- Real screens only. Any decorative image must be generated by GPT (owner rule).

## 2. Landing pages

1. Copy `_templates/app-landing.html` → `newapp/index.html`.
2. Replace every `{{...}}`. Copy comes from the app's `AppStore/PRODUCT_PAGE_FINAL.md`
   (promotional text, description, screenshot captions). No hype, no medical claims.
3. Japanese: copy your finished page → `ja/newapp/index.html`. Set `lang="ja"`, translate,
   use `-ja` images, `privacy-ja.html` / `support-ja.html`, logo link `/ja/`, language link → `/newapp/`.
   If the app itself is English only, say so on the Japanese page.
4. Add a colour palette in `assets/site.css` next to the others: copy the `.t-pillwindow` lines
   (light + dark) and rename to `.t-newapp`. Take colours from the app icon.

## 3. Home pages (EN + JA)

In both `index.html` and `ja/index.html`:
- Paste `_templates/app-card.html` inside `<div class="cards">` (JA wording is noted in the template).
- Add a chip to the `.hero-apps` list and a line to the footer "Velkmoor" list (with the privacy link).

## 4. Privacy and support

- `newapp/privacy.html`, `privacy-ja.html`, `support.html`, `support-ja.html` (copy an existing app's
  pages; they use `assets/app.css`). The brand link at the top points to `./` (EN) or `/ja/newapp/` (JA).
- The App Store description must link to `https://velkmoor.com/newapp/support.html` and `/privacy.html`.

## 5. When the app goes live

Search the site for `APP_STORE_LINK` and `data-app-store="newapp"` (home EN + JA, landing EN + JA).
Replace each `<span class="badge" …>Coming soon…</span>` with Apple's **official** "Download on the
App Store" badge artwork (Apple Marketing Tools; English badge on EN pages, Japanese badge on JA pages),
saved under `assets/img/`, wrapped in `<a href="https://apps.apple.com/app/id…">`. Do not recolour or
restyle the badge. Never add a store link before the app is live.

## 6. Check before committing

```
python3 -m http.server 8765        # then open http://localhost:8765/newapp/
python3 _tools/check_links.py      # every internal link and image must resolve
grep -rn "{{" --include='*.html' . | grep -v _templates   # must print nothing
```

- Look at the page at desktop width and at 390px, in light and dark mode.
- Older apps (Dry Days, 血圧手帳 …) stay listed in the home-page footer under "Other apps".
- Commit locally. The owner pushes.
